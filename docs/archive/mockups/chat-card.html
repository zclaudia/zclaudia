B · One card

  • Most literal. Header, transcript, composer and selectors row all live in one card, a peer of the Terminal / Memory cards.
  • The header (title, Codex CLI, panel toggle) gets card padding and a hairline under it, so it feels like a pane tab bar.

C · Header on canvas

  • My pick. Title and controls stay on the canvas exactly where they are today; only the conversation is carded.
  • Matches the right column, whose tab bars live inside cards while the window-level controls stay outside.

D · Composer card

  • The transcript and the composer become two cards. The composer card holds the pill and the Default / Model / Root row, so the selectors are no longer floating on the canvas.
  • Strongest card look, but it costs one more gutter of height.

What the real UI changes

  • Contrast is the weak point. Canvas is --background (97), card is --card (99): only +2 in light. The right cards survive on border + shadow-md, and the chat card would too. This is the problem the recessed tray solved and 8f91059e removed, so the Canvas: sidebar dial shows the tray look again (+6) as an option.
  • The assistant bubble disappears. Today it's a --card bubble on --background; inside a --card chat card it would be white on white. Two ways out: Flat (no bubble, only the user message is boxed) or Tinted bubble (--muted, with tool rows and diffs flipping to --card). I'd go Flat.
  • The user bubble loses its shadow inside the card (--secondary alone is enough).
  • Composer. The grey pill stays as is in B / C. In D the pill sits inside its own card, so the two greys would be redundant; I'd keep the pill anyway to preserve the shape.
  • Sparse vs Busy. The empty-ish card in your screenshot is a lot of blank card; flip to Busy to see it with a real conversation.
  • Not covered: mobile (I'd leave it flat), Home / Settings modes, overlays.
